[0:20] INTRO — เกมนี้คืออะไร
--------------------------------------------------------------
[ภาพ: เดินใน Hideout -> เข้า portal -> แผนที่ผุดขึ้นมา]

สวัสดีครับ นี่คือ Devlog ตอนแรกของเกมที่ผมทำอยู่คนเดียว
ตอนนี้ยังไม่มีชื่อ ในเครื่องผมเรียกมันว่า Project-A (หัวเราะ)

เป็นเกม ARPG แนว Path of Exile มุมกล้องมองเฉียงลงมา
มีบ้านเรียกว่า Hideout เดินเข้า portal แล้วจะไปแผนที่ที่สุ่มสร้างใหม่ทุกครั้ง
เข้าไปฆ่ามอน ได้ของ กลับบ้าน วนไป

[ภาพ: ซูมให้เห็นเส้นดินสอบนตัวละครและต้นไม้]

แล้วภาพผมอยากให้ออกมาเหมือนวาดด้วยดินสอ อันนี้เดี๋ยวเล่าครับ

[ภาพ: หน้า CLAUDE.md หรือไดอะแกรม host / client]

อีกเรื่องที่ตั้งใจไว้ตั้งแต่วันแรก คือผมอยากให้เล่นกับเพื่อนได้ ปาร์ตี้สองถึงหกคน
ตอนนี้ยังเล่นคนเดียวนะครับ แต่ผมเขียนโค้ดทุกอย่างเผื่อไว้แล้ว
อันนี้จะเป็นเรื่องที่โผล่มาตลอดทั้งคลิป


--------------------------------------------------------------
[1:15] วันที่ 1 — พื้นที่สุ่มเองได้
--------------------------------------------------------------
[ภาพ: กด regenerate หลาย ๆ ครั้ง แผนที่เปลี่ยนรูปทุกครั้ง]

ผมเริ่มจากระบบสร้างแผนที่ เพราะเป็นหัวใจของเกมแนวนี้
ตอนแรกเป็นเกาะหญ้า สุ่มรูปร่าง โปรยต้นไม้กับหิน มีใต้เกาะห้อยลงไปด้วย

[ภาพ: animation แผนที่ผุดขึ้นมาทีละส่วน]

แล้วก็ทำให้ตอนเข้าแผนที่ พื้นค่อย ๆ ผุดขึ้นมาแบบนี้
ไม่จำเป็นเลยครับ แต่ทำแล้วชอบ (ยิ้ม)

[ภาพ: ตัวละครแคปซูลเดินบนพื้น + กล้องตาม]

วันเดียวกันก็ได้กล้องมุมเฉียง กับตัวละครที่ยังเป็นแท่งแคปซูลเดินได้


--------------------------------------------------------------
[2:00] แผนที่ขั้นบันได + seed
--------------------------------------------------------------
[ภาพ: แผนที่แบบหลายชั้น มีทางลาด หน้าผา บ่อน้ำ]

แผนที่ราบ ๆ มันน่าเบื่อ ผมเลยทำให้มีหลายชั้น มีทางลาดขึ้นลง มีหน้าผา มีบ่อน้ำ
บางบ่อลุยน้ำเดินผ่านได้ด้วย

[ภาพ: ใส่ seed เดิมสองครั้ง ได้แผนที่หน้าตาเหมือนกัน]

จุดสำคัญคือทุกอย่างสุ่มจาก "seed" ตัวเลขตัวเดียว
seed เดิม ได้แผนที่เดิมเป๊ะทุกครั้ง

ทำไมต้องสนใจ? เพราะตอนเล่นกับเพื่อน ผมไม่ต้องส่งแผนที่ทั้งก้อนไปให้ทุกเครื่อง
ส่งแค่ตัวเลขตัวเดียว แต่ละเครื่องสร้างแผนที่เหมือนกันเอง ประหยัดเน็ตไปเยอะมาก


--------------------------------------------------------------
[2:45] ตัวละครที่เดินแล้วรู้สึกดี
--------------------------------------------------------------
[ภาพ: เดินขึ้นทางลาด ไถลตามกำแพง กระโดดหลายจังหวะ แตะ dash กดค้างวิ่ง]

ช่วงนี้หมดเวลาไปกับการทำให้เดินแล้วรู้สึกดีเยอะมาก
เดินขึ้นทางลาดไม่ติด ชนกำแพงแล้วไถลไปตามกำแพง กระโดดได้หลายจังหวะ
แล้วก็ปุ่มเดียว แตะทีเดียวเป็น dash กดค้างเป็นวิ่ง

[ภาพ: เดินเข้าหลังต้นไม้/หน้าผา แล้วของที่บังจางลง เห็นเส้นขอบ]

กล้องมุมนี้มีปัญหาคลาสสิก คือตัวละครเดินหลบหลังต้นไม้แล้วมองไม่เห็น
ผมเลยทำให้ของที่บังค่อย ๆ จางลงแล้วมีเส้นขอบให้เห็น


--------------------------------------------------------------
[3:30] Hideout กับ Portal
--------------------------------------------------------------
[ภาพ: Hideout -> เดินไปที่ portal มีป้าย "Click me!!" -> คลิก -> จอดำ -> แผนที่]

เกมแนวนี้ต้องมีบ้าน ผมเลยแยกเป็นสองฉาก คือ Hideout กับแผนที่สุ่ม
เดินไปใกล้ portal แล้วคลิก จอค่อย ๆ มืด โหลดฉาก แล้วค่อย ๆ สว่างกลับมา

[ภาพ: เข้าออก portal ไปกลับ ตัวละครเดิมตลอด]

ตัวละครเป็นตัวเดียวกันตลอดข้ามฉาก ไม่ได้สร้างใหม่ทุกรอบ
ของที่ถืออยู่หรือค่าต่าง ๆ จะได้ไม่หายตอนวาร์ป


--------------------------------------------------------------
[4:10] วันที่ 5 — ตัวละครมีชีวิต + สไตล์ดินสอ
--------------------------------------------------------------
[ภาพ: เปลี่ยนจากแคปซูลเป็นโมเดลคน เดิน วิ่ง กระโดด ลงพื้น]

แคปซูลกลายเป็นคนแล้วครับ มีท่าเดิน วิ่ง กระโดด
ท่ากระโดดผมแบ่งเป็นสี่ช่วง ตอนย่อ ตอนลอยขึ้น ตอนตก แล้วก็ตอนลงพื้น

(เล่าเหมือนบ่น)
มีบั๊กตลก ๆ ด้วย วิ่งขึ้นทางลาดแล้วตัวละครทำท่ากระโดดเอง
เพราะตอนแรกผมเดาว่ากระโดดจากความเร็วแนวตั้ง ขึ้นทางลาดมันก็มีความเร็วแนวตั้ง
แก้โดยเช็คว่า "กดปุ่มกระโดดจริงไหม" แทน

[ภาพ: dash แล้วมีร่างเงาทิ้งไว้ข้างหลัง (slow-mo)]

แล้วก็ dash ทิ้งร่างเงาแบบ Rockman อันนี้ชอบมาก

[ภาพ: เปรียบเทียบก่อน/หลังใส่ pencil shader — สไลด์ซ้ายขวา]

แล้วก็มาถึงสไตล์ภาพ
ผมเขียน shader ที่หาขอบของทุกอย่างในฉาก แล้ววาดออกมาเป็นเส้นดินสอ
เส้นสั่นนิด ๆ เหมือนวาดมือ เส้นซ้อนสองชั้น มีเนื้อดินสอ
ใส่ให้ตัวละคร ต้นไม้ พื้นหญ้า แล้วเกมดูมีตัวตนขึ้นเยอะเลยครับ

[5:15] วันที่ 6–7 — ต่อยได้แล้ว!
--------------------------------------------------------------
[ภาพ: ต่อยมอนครั้งแรก เลขดาเมจเด้ง มอนกระเด็นตาย]

ตอนนี้แหละที่มันเริ่มเป็นเกม
ต่อยได้ มีเลขดาเมจ ตายแล้วกระเด็นไปทางที่โดนตี

[ภาพ: เปิด gizmo nav graph เห็นเส้นทางเดินของ AI บนแผนที่]

ศัตรูเดินบนแผนที่ที่สุ่มสร้างได้ เพราะทุกครั้งที่สร้างแผนที่ ผมสร้างกราฟทางเดินให้ AI ไปด้วย
ตรงไหนเดินได้ ตรงไหนต้องกระโดดขึ้น ตรงไหนกระโดดลง

[ภาพ: ฝูงมอนเดินเล่น -> ตัวหนึ่งเห็นเรา -> ทั้งฝูงวิ่งมารุม / มอนกระโดดลงจากหน้าผา]

มอนมาเป็นฝูง เดินเล่นด้วยกัน ตัวหนึ่งเห็นเรา เพื่อนวิ่งมารุมทั้งฝูง
ตอนไล่ก็กระโดดข้ามชั้นตามมาได้

[ภาพ: มอน Elite ตัวใหญ่เรืองแสง]

แล้วก็มีตัว Elite ตัวใหญ่ เรืองแสง เลือดเยอะ ตีแรง

(จริงจังขึ้นนิด)
ตรงนี้ขอเล่าเรื่องโค้ดนิดนึง
ตอนกดต่อย ฝั่งผู้เล่นไม่ได้บอกว่า "ฉันทำดาเมจ 50" แต่บอกว่า "ขอต่อยตรงนี้"
แล้วเกมฝั่ง server เป็นคนเช็คว่าต่อยได้ไหม โดนใคร โดนเท่าไหร่
อนาคตเล่นออนไลน์ คนโกงจะได้แก้ตัวเลขตัวเองไม่ได้

[7:30] วันที่ 9 — ไอเทมและของดรอป
--------------------------------------------------------------
[ภาพ: Project window โฟลเดอร์ Items -> Inspector ไอเทม]

ต่อยได้แล้ว ก็ต้องมีของดรอป
ไอเทมตอนนี้มีสองแบบ ของสวมใส่ อย่างหมวก รองเท้า แหวน แล้วก็ของกดใช้ อย่างยา
ค่าสเตตัสของไอเทมใช้สูตรเดียวกับ gem เลย ผมเขียนสูตรนี้ไว้ที่เดียว แล้วใช้ทั้งเกม

[ภาพ: ต่อยมอนตาย ไม่มีของตกพื้น -> วาร์ปกลับบ้าน -> คลิกกล่อง -> รายการของเด้ง]

ตรงนี้ผมทำต่างจาก PoE คือของไม่ตกพื้นครับ
มอนตาย ของส่งตรงเข้ากล่องที่บ้าน เคลียร์แผนที่เสร็จ กลับมาเปิดดูว่ารอบนี้ได้อะไร
ไอคอนอยู่ข้างหน้า สีชื่อบอกความหายาก

[ภาพ: มีของในกล่อง -> ไม่เปิด -> เข้าแผนที่ใหม่ -> กลับมา กล่องว่าง]

แต่ถ้าลืมกลับมาเปิด แล้วเข้าแผนที่ใหม่เลย... ของเก่าหายหมดครับ
(หยุด) ตั้งใจ ผมอยากให้การกลับบ้านมาเปิดกล่องเป็นจังหวะหนึ่งของเกม
ใครว่าโหดไป คอมเมนต์มาเถียงกันได้ครับ (หัวเราะ)

[ภาพ: ซูมไอคอน]

ไอคอนตอนนี้ให้โค้ดวาดเป็นรูปทรงง่าย ๆ ไปก่อน เดี๋ยวค่อยมีรูปจริง

[1:15] วันที่ 1 — แผนที่สุ่ม
--------------------------------------------------------------
[ภาพ: กด regenerate หลายครั้ง / animation พื้นผุดขึ้นทีละส่วน]

วันแรกผมเริ่มที่แผนที่ เพราะเป็นหัวใจของเกมแนวนี้

แล้วก็ทำให้พื้นค่อย ๆ ผุดขึ้นมาตอนเข้าแผนที่ ไม่จำเป็นเลย แต่ทำแล้วชอบ (ยิ้ม)

[ภาพ: แผนที่หลายชั้น ทางลาด หน้าผา บ่อน้ำ / seed เดิมสองครั้ง แบ่งจอเทียบ]

ต่อมาก็เป็นแผนที่หลายชั้น มีทางลาด หน้าผา บ่อน้ำ
ทุกอย่างสุ่มจากตัวเลขตัวเดียวที่เรียกว่า seed
seed เดิมได้แผนที่เดิมเป๊ะ ไว้ตอนเล่นกับเพื่อน ส่งแค่ตัวเลขก็พอ ไม่ต้องส่งแผนที่ทั้งก้อน

[6:50] Passive Tree
--------------------------------------------------------------
[ภาพ: กด P เปิด Passive Tree ซูมออกให้เห็นทั้งต้น แล้วซูมเข้า]

แล้วก็สิ่งที่ทุกคนรอ ถ้าทำเกมแนว PoE ไม่มีอันนี้ไม่ได้
Passive Tree ครับ

ได้แต้มทุกครั้งที่เลเวลอัป ลงแต้มได้เฉพาะจุดที่ติดกับจุดที่ลงไว้แล้ว

[ภาพ: คลิกขวาคืนแต้มจุดกลางเส้น -> ไม่ยอม / คืนจุดปลายเส้น -> ได้]

คืนแต้มก็ได้ แต่ต้องไม่ทำให้ต้นไม้ขาดตอน
จะดึงจุดตรงกลางออกแล้วปล่อยปลายลอยไว้ไม่ได้

[ภาพ: เลื่อนดูสามสาย Str / Dex / Int]

ต้นไม้แตกเป็นสามสาย
Strength เพิ่มเลือดกับดาเมจ Dexterity เพิ่มความเร็วโจมตี Intelligence เพิ่มมานา

[ภาพ: หน้าต่าง Passive Tree Editor ใน Unity — ลากจุด Shift+คลิกเชื่อม คลิกขวาเพิ่มจุด]

(จริงจังขึ้นนิด)
ส่วนที่ผมภูมิใจคือเครื่องมือข้างหลัง
ผมทำ editor ของตัวเองไว้วาดต้นไม้ใน Unity
ลากจุด Shift คลิกเพื่อเชื่อม คลิกขวาเพิ่มจุด มีปุ่มใส่สเตตัสสำเร็จรูป
ต้นไม้ของ PoE มีเป็นพันจุด ถ้าไม่มีเครื่องมือแบบนี้ ผมไม่รอดแน่นอน

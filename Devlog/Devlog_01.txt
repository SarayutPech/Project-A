==============================================================
 Project-A DEVLOG #01 — จากพื้นหญ้าว่าง ๆ สู่ ARPG ที่ต่อยได้และมีของดรอป
 ช่วงเวลา: 2026-09-23 (commit แรก) -> 2026-10-01
 Engine: Unity 6000.6 / URP / Input System ตัวใหม่
 สถานะ: Prototype (เล่นคนเดียว ยังไม่มี server)
==============================================================

[เกมนี้คืออะไร]
ARPG แนว Path of Exile มุมกล้อง isometric
- มี Hideout เป็นบ้าน เดินเข้า portal แล้ววาร์ปไปแผนที่ที่สุ่มสร้างใหม่ทุกครั้ง (procedural map)
- ต่อสู้แบบประชิด สกิลมาจาก "gem" แบบ PoE (active gem + support gem)
- ภาพเป็นสไตล์ลายเส้นดินสอ (pencil sketch)
- เป้าหมายระยะยาว: co-op ปาร์ตี้ 2–6 คน -> ต่อไปขยายเป็น dedicated server

[ตัวเลขรอบนี้]
- 9 วัน / 28 commits
- ระบบหลักที่มีแล้ว: แผนที่สุ่ม, ตัวละคร + การเคลื่อนที่, กล้อง, สลับ scene,
  การต่อสู้, AI ศัตรู, ระบบสกิล gem, stat sheet, ไอเทม, ของดรอป


==============================================================
 ช่วงที่ 1 — เริ่มโปรเจกต์: พื้นหญ้าที่สุ่มสร้าง (23 ก.ย.)
==============================================================
- commit แรก: ระบบสร้างพื้นแบบสุ่ม (ProceduralWanderingGround)
  พื้นหญ้าเป็นเกาะ มีใต้เกาะ (IslandUndersideBuilder) โปรยต้นไม้/หิน แล้วรวม mesh ลด draw call
- Shader Graph พื้นหญ้าแบบตาราง (GrassGrid)
- แอนิเมชันตอนสร้างแผนที่ (MapBuildAnimator): พื้นค่อย ๆ ผุดขึ้นมาทีละส่วน ตั้งค่าได้ผ่าน config
- กล้อง isometric + ตัวละครเดินได้ครั้งแรก (PlayerMovement, PlayerSpawner)
- ขอบแผนที่กันตกเกาะ (MapBoundaryBuilder)


==============================================================
 ช่วงที่ 2 — แผนที่จริงจังขึ้น + ระบบ scene (26 ก.ย.)
==============================================================
แผนที่
- แยกค่าตั้งแผนที่เป็น ScriptableObject (ProceduralMapConfig) -> หนึ่ง asset = หนึ่งแบบแผนที่
- แผนที่แบบขั้นบันได (TerraceLayout): มีหลายชั้น มีทางลาด มีหน้าผา
  สุ่มจาก seed ด้วย System.Random ของตัวเอง -> seed เดิมได้แผนที่เดิมเป๊ะ (สำคัญมากตอนทำ multiplayer)
- บ่อน้ำ: วางได้ทุกชั้น บางบ่อลุยน้ำเดินผ่านได้
- จุดเกิด/portal ไม่ไปเกิดในน้ำ และวางบนความสูงพื้นจริง
- แบ่งพื้นเป็น chunk ตามชั้น (พื้น/ทางลาด/หน้าผา) แก้ warning mesh collider 2 ล้านสามเหลี่ยม
- ไม่เซฟแผนที่ที่ generate ลง scene (สร้างใหม่ตอนเล่นทุกครั้ง)

กล้อง / ภาพ
- ของที่บังตัวละคร (ต้นไม้ หน้าผา) จะค่อย ๆ จางลงเห็นทะลุ + มีเส้นขอบ (OcclusionOutlineController)
- จุดเกิดใหม่ที่ปลอดภัย + ปรับกล้อง

ตัวละคร
- เดินตามระนาบพื้น ไม่ติดทางลาด, ไถลไปตามกำแพง, กำหนดมุมลาดสูงสุดที่เดินขึ้นได้
- กระโดดได้หลายครั้ง (double / multi jump), กดค้างกระโดดอัตโนมัติ
- ปุ่มเดียว: แตะ = dash / กดค้าง = วิ่ง

Scene flow
- SceneTransition: จอดำ fade -> โหลด scene -> fade กลับ
- ScenePortal: เดินเข้าระยะแล้วคลิกเพื่อวาร์ป + particle portal
- แยก scene เป็น Hideout (บ้าน) กับ CreatedMap (แผนที่สุ่ม)
- ตั้ง build profile WebGL

วางกฎการเขียนโค้ด (CLAUDE.md)
- ตัดสินใจตั้งแต่ตอนนี้ว่าจะทำ co-op และอนาคตเป็น dedicated server
- กฎหลัก: logic เกมตัดสินฝั่ง server, แยกภาพออกจาก logic, ไม่ผูกโค้ดกับ "ผู้เล่นคนเดียว",
  แผนที่สร้างซ้ำได้จาก seed, ข้อมูลผู้เล่นผ่าน interface, ไม่เชื่อค่าจาก client


==============================================================
 ช่วงที่ 3 — ตัวละครมีชีวิต + สไตล์ดินสอ (27 ก.ย.)
==============================================================
- ใส่โมเดลตัวละคร + แอนิเมชัน Humanoid: Idle / Walk / Run / Jump (แยก 4 ท่า) / Dash / Roll
- Animator state machine: blend เดิน-วิ่ง, กระโดดขึ้น-ลอย-ตก-ลงพื้น, dash
  กระโดดดูจากจำนวนครั้งที่กดจริง ไม่เดาจากความเร็ว -> วิ่งขึ้นทางลาดไม่เด้งเป็นท่ากระโดด
- Dash afterimage แบบ Rockman: ระหว่าง dash ทิ้งร่างเงาเรือง ๆ ไว้เป็นระยะแล้วค่อยจาง
  (ใช้ pool + ลบ mesh/material เองกันหน่วยความจำรั่ว)
- ตัวละครตัวเดียวอยู่ข้าม scene (DontDestroyOnLoad) เปลี่ยน scene แล้วย้ายตัวเดิมมาวาง ไม่สร้างใหม่
- แก้บั๊ก
    ก้นบ่อน้ำต่ำกว่าเท้า เงาเลยดูลอย -> ให้ก้นบ่อตามระดับพื้นที่เท้าเหยียบ
    dash ลงทางลาดแล้วลอยค้าง -> จบ dash แล้วดูดกลับลงพื้น
    ยืนชิดกำแพงแล้วเส้นขอบตัวบังหาย -> เปลี่ยนวิธีเช็ค
- Pencil shader (PencilEdge.hlsl): หาขอบจาก depth + normal วาดเป็นเส้นดินสอ
  เส้นสั่นเป็นจังหวะ (boil) เส้นซ้อน 2 ชั้น เนื้อ graphite -> ใส่ให้ตัวละคร ต้นไม้ พื้นหญ้า
- BillboardText: ข้อความลอยหันเข้ากล้อง ลอยขึ้นลง/ขยายย่อได้ -> ทำป้ายบอกทางใน Hideout และป้าย portal


==============================================================
 ช่วงที่ 4 — ต่อยได้แล้ว! การต่อสู้ + AI + สกิล gem (28–29 ก.ย.)
==============================================================
การต่อสู้
- Health: HP + ทีม, ตายแล้วกระเด็นไปทางที่โดนตี
- MeleeAttack: หนึ่งท่ามีได้หลาย hitbox จังหวะเป็นสัดส่วนของท่า (ไม่พึ่ง animation event)
  มีท่าแบบ channel (กดค้างวนท่า), cooldown แยกต่อสกิล
- เลขดาเมจลอย (DamageNumbers) ใช้ pool
- ฝั่งผู้เล่น "ขอโจมตี" -> ฝั่ง server เช็คก่อนค่อยตีจริง (PlayerCombat)

ศัตรู
- ใช้โมเดลเดียวกับผู้เล่น สลับท่าต่อยเป็น Boxing
- EnemyMotor: กระโดดข้ามชั้นแบบวิถีโค้ง
- EnemyAI: เดินเล่น -> สงสัย -> ไล่ -> ตาย
- เกิดเป็นฝูง (pack) เดินเล่นรอบจุดกลางด้วยกัน ตัวหนึ่งเจอผู้เล่น เพื่อนมารุม
- Elite: ตัวใหญ่ เรืองแสง เลือด/ดาเมจเพิ่ม
- ทุกอย่างสุ่มจาก seed ของแผนที่
- MapNavGraph: กราฟทางเดินของ AI สร้างจากโครงขั้นบันได (เดิน / กระโดดขึ้น / กระโดดลง) ดูเป็น gizmo ได้

ระบบสกิล gem แบบ PoE
- ActiveSkillGem (ท่า + แอนิเมชัน) / SupportGem (ปรับค่า Flat / Increased% / More%)
- ผู้เล่นมีหลาย slot แต่ละ slot = active 1 + support 5 ช่อง ตั้งปุ่มต่อ slot ได้ (rebind ได้)
- PlayerStats: stat sheet ที่เดียวของตัวละคร (Max HP / ความเร็วเดิน / ความเร็วตี) ทุกระบบแค่เพิ่ม/ถอด modifier
- รวม mesh ของแผนที่ตอนเล่น (static batching) ลด draw call

สกิลแรก ๆ (29 ก.ย.)
- Punch: ต่อยคอมโบ Boxing / Hook / Uppercut สุ่มท่าไม่ซ้ำติดกัน ผสมท่าหลบ (Dodging)
- ต่อยท่อนบนอย่างเดียวได้ ขายังเดินตาม (Animator layer UpperBody + avatar mask)
- Hurricane Kick
- Flicker Strike: วาร์ปไปข้างศัตรูใกล้เคอร์เซอร์แล้วตี กดค้างวาร์ปไล่ทั้งฝูง
- Shadow clones: ร่างเงาออกมาตีพร้อมเรา (ดาเมจจริง ไม่ใช่แค่ภาพ)
- gem ใหม่: ความเร็วตีฐาน, พื้นที่ (area), สุ่มท่า, กลับข้างท่า (mirror)


==============================================================
 ช่วงที่ 5 — ไอเทม + ของดรอป (1 ต.ค.)
==============================================================
ไอเทม (ScriptableObject)
- ItemDefinition: id, ชื่อ, คำอธิบาย, icon, rarity (Normal / Magic / Rare / Unique สีแบบ PoE)
- EquipmentItem (ของสวมใส่): Weapon, OffHand, Helmet, BodyArmour, Gloves, Boots, Belt, Amulet, Ring x2
  ค่าสเตตัสใช้ StatModifier สูตรเดียวกับ gem
- ConsumableItem (ของกดใช้): เติม HP, บัฟชั่วคราว, cooldown แยกต่อชนิด
- ของตัวอย่าง: Iron Helmet, Leather Boots, Ruby Ring, Swift Gloves, Life Flask, Quicksilver Flask
  (ไอคอนตอนนี้วาดด้วยโค้ดเป็นรูปทรงง่าย ๆ ไปก่อน)

ของดรอป
- ศัตรูตาย -> สุ่มจาก Loot Table (Elite สุ่ม 3 เท่า)
- ของ "ไม่ตกพื้น" ส่งตรงเข้ากล่องรับของ ไปเปิดดูที่ Hideout
- LootChest ใน Hideout: คลิกแล้วขึ้นรายการ [ไอคอน] ชื่อไอเทม xจำนวน ของชนิดเดียวกันรวมแถวเดียว
- เข้า map ใหม่ = ของที่ยังไม่ได้เก็บหายหมด (ตั้งใจ ให้กลับบ้านมาดูของเป็นจังหวะหนึ่งของเกม)
- ของแต่ละชิ้นมี id เก็บได้ครั้งเดียว / เซฟเป็น JSON ในเครื่อง (ภายหลังเปลี่ยนเป็น backend ได้)

เก็บกวาด
- แยกระบบ "เดินเข้าระยะแล้วคลิก" ออกมาใช้ร่วมกัน (ClickInteractable) -> portal กับกล่องใช้ตัวเดียวกัน
- คลิกเปิดกล่อง/portal แล้วไม่กลายเป็นการต่อย

==============================================================
 สิ่งที่ได้เรียนรู้
==============================================================
- วางกฎ multiplayer ตั้งแต่ต้นคุ้มมาก ระบบใหม่ (สกิล ศัตรู ไอเทม) เขียนให้ตัดสินฝั่ง server ได้เลย ไม่ต้องรื้อทีหลัง
- seed สำคัญ: แผนที่ ฝูงศัตรู elite สุ่มจาก seed ทั้งหมด -> ทดสอบซ้ำได้ และต่อไปส่งผ่านเน็ตแค่ seed
- สูตรสเตตัสสูตรเดียว (flat / increased / more) ใช้ได้ทั้ง gem, stat ตัวละคร, elite, ไอเทม
- แยกภาพออกจาก logic ทำให้เพิ่มลูกเล่นภาพ (afterimage, shadow clone, เส้นดินสอ) ได้โดยไม่กระทบ gameplay
